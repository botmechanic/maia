# Maia Design Principles: Warm Architectural Precision × Apple Minimalism

Maia's visual language pairs the tactile warmth of archival stationery and terracotta pottery with the calm, uncluttered clarity of Apple's flagship apps.

## Core Rules
1. **Minimalistic Copy Over Verbosity:** Stitch mockups in [`reference-screens/`](reference-screens/) are visual structure references—always edit down verbose paragraphs into crisp, calm, 1-line human labels.
2. **One Primary Action Per Screen:** Reserve terracotta (`#AF4F35`) strictly for Maia's orb and at most **one** primary pill CTA per viewport.
3. **Hairlines Over Shadows:** Use tonal contrast (`#F8F5F0` canvas vs `#FFFFFF` cards) and `1dp` `#E8E2D9` borders instead of muddy drop shadows. Reserve soft micro-shadows solely for floating system chrome (the floating pill nav bar and chat composer).
4. **Floating Chrome:**
   - **Unified Top Bar:** 28dp breathing orb + `ON DEVICE` pill + minimal shield icon.
   - **Floating Pill Bottom Bar:** Centered `56dp` pill suspended above the navigation bar with `1dp` hairline.
   - **Floating Pill Composer:** `48dp` pill input with left mic icon and right `36dp` circular terracotta send trigger.
5. **Uncontained Companion Voice:** Maia's replies sit directly on the warm canvas as clean ink text; user messages use grounded `userBubble` (`#EFEAE2`) with a `20dp` radius and `4dp` bottom-right tuck.
6. **Typography & Tabular Numerals:** Crisp geometric sans-serif (`Plus Jakarta Sans` / system sans) with tight editorial headlines, generous `17sp / 26sp` body reading rhythm, and `tnum` tabular numerals on all metrics and timestamps.
